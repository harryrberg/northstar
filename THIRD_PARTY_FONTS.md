# Third-party font

The classic 80-column view includes **Px437 IBM VGA 8x16**, an outline recreation by VileR. The font is licensed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). The file is included unchanged.

- Creator and original distribution: [VileR, The Ultimate Oldschool PC Font Pack](https://int10h.org/oldschool-pc-fonts/)

- Source of this copy: [SDC-UDA at commit 61926e8](https://github.com/hyeongyu-kim/SDC-UDA/blob/61926e8f461e741cc46d12d0b6c99614acfef5a8/Px437_IBM_VGA_8x16.ttf)
- SHA-256: `46eee11f51c5f303e6372e96e771ffe93ce6c22d7d2937ecf06db56b7a19d447`

The font's embedded metadata identifies VileR, version `v2.0-2020-07`, and the CC BY-SA 4.0 license. OpenStar's code and original documentation remain under GPL-3.0-only; this font retains its own license.

The default view uses **IBM Plex Mono Regular**, included unchanged under the [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/).

- Creator and original distribution: [IBM Plex](https://github.com/IBM/plex)
- Font file: `crates/openstar-desktop/assets/fonts/IBMPlexMono-Regular.ttf`
- Source: [IBM/plex at commit 3927691](https://github.com/IBM/plex/blob/39276912b05f700ee1dd491950c35d8697214208/packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Regular.ttf)
- SHA-256: `7c6fbddca4b700be918f5f6183d9bd4464fa427fe435f0b480d77fe2bb8c5a43`
- Copyright notice and full license: [`IBM-Plex-OFL.txt`](crates/openstar-desktop/assets/fonts/IBM-Plex-OFL.txt)

F12 selects the VGA recreation for readers who prefer its original pixel shapes. Both fonts cover the box-drawing characters in the retained 80-column screen. F11 toggles full screen.
