# Windows desktop prototype

Build with Rust 1.99 and run `cargo run -p openstar-desktop -- path/to/document.doc`. Omitting the path opens the WordStar-style main menu. D opens or creates a document; X exits. The window starts on a black 80-column, 25-row screen. F11 toggles full screen, and F12 changes between IBM Plex Mono and a recreated VGA 8x16 font. Both modes use the same cell positions and line spacing. Plex keeps its original glyph proportions and is drawn at five-sixths of the VGA font size so its wider advance fits the shared cell width. The document model and screen cells do not change when the font changes. IBM Plex Mono is the default because the VGA shapes look coarse on a high-resolution full-screen display.

The implemented editing commands are Ctrl-S and Ctrl-D for left/right, Ctrl-A and Ctrl-F for word left/right, Ctrl-E and Ctrl-X for a physical line up/down, Backspace for deletion before the cursor, Delete or Ctrl-G for deletion under the cursor, Ctrl-T for word deletion, Ctrl-Y for line deletion, Ctrl-U for inserting the last erased text, Ctrl-N for a bounded hard return, Ctrl-K B/K for block marks, Ctrl-K C for block copy, Ctrl-K V for same-line block move, Ctrl-K Y for bounded block delete across at most one ordinary hard break, Ctrl-Q A for bounded search and replace, Ctrl-Q R for document start, Ctrl-Q S/D for the start/end of the current physical line, Ctrl-Q B/K for block markers, Ctrl-Q C for document end, Ctrl-V for insert/overwrite, Ctrl-B for paragraph alignment, Enter for a line break, and Ctrl-K S for saving the current file. Ctrl-K D saves and returns to the main menu. Ctrl-Shift-S is Save As to a new path. Ctrl-K Q returns to the menu after an unsaved-change check. Arrow Left/Right/Up/Down, Insert, F1, F7, F9 (save), and F10 (save and done) are additional prototype shortcuts. The DOS menu still displays commands that are not implemented. F1 lists the current subset. [Ctrl-N evidence and limits](HARD_BREAK.md).

Ctrl-Q F opens the DOS-style search prompt in legacy mode. Enter a literal ASCII term, press Enter, then enter any combination of W (whole words), U (ignore case), and B (backwards) and press Enter again. Ctrl-L repeats the search. Escape cancels the prompt or dismisses a failed-search message. [Search evidence and limits](FIND.md) cover the declared behavior. The G and wildcard options shown on the prompt are not yet supported.

F2 at the opening menu starts an empty native UTF-8 document. F3 opens a selected UTF-8 file or starts a new document at a missing path. `openstar-desktop --utf8 FILE` opens an existing UTF-8 file explicitly. In this mode, typing, Ctrl-V paste, IME commit events, Left/Right or Ctrl-S/Ctrl-D, Backspace/Delete, Enter, and Ctrl-Q R edit plain UTF-8. Ctrl-Z undoes an edit; Ctrl-Y or Ctrl-Shift-Z redoes it. Up/Down or Ctrl-E/Ctrl-X move through visual rows. The preferred column survives shorter rows, and the document scrolls when the cursor reaches the viewport edge. Long text wraps at word spaces within 78 text cells; longer words break at the edge. These soft breaks do not enter the file. Ctrl-K S saves to the current path. F4 on the opening menu finds an unsaved recovery copy for either document mode. Existing UTF-8 bytes are not normalized. One-cell characters such as Ã¦, Ã¸ and Ã¥ display directly; unsupported or wide graphemes display a square without changing the stored text. See [the format decision](decisions/0002-utf8-documents.md) for the exact boundary.

Saving an existing document replaces its current path after writing a backup of the previous bytes. WordStar mode uses `.BAK`; UTF-8 mode appends `.bak` to the full file name. A disk file changed since opening or last saving is rejected with a message, and Save As can preserve the in-memory edits at a new path. Save As refuses to overwrite an existing path. [Save behavior and limits](SAVING.md) describes the storage guarantees and unverified races. Reading is limited to 1 MiB. The WordStar mode handles printable ASCII. Norwegian letters, IME, pasted document text, deletion outside the bounded Backspace/Delete, Ctrl-G, Ctrl-T, and Ctrl-Y/Ctrl-U profiles, navigation outside the bounded vertical and word profiles, block operations outside marking and copy, undo, and general WordStar formatting remain unfinished there. UTF-8 mode supports bounded undo/redo and separate recovery snapshots; [the recovery contract](RECOVERY.md) describes timing and limits. Original legacy data after EOF remains in the saved carrier but is not displayed. Unsupported control glyphs are not yet qualified. No accessibility or multi-display claim has been verified.
