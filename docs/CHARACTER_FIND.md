# One-character search

In legacy mode, Ctrl-Q G asks `Find what?` and searches forward as soon as one letter is typed. Ctrl-Q H does the same backwards. Forward search includes the current cell; backward search starts before it. Both distinguish uppercase from lowercase and put the cursor on the found letter. They cross a hard CRLF. A repeated forward search can find the same letter again at the current cell. A failed forward search moves to active EOF; a failed backward search moves to document start. The failure display says `Could not find: Z` for a searched `Z` and waits for Esc. The document bytes and Insert mode do not change.

The reference is WordStar Professional 4.00 `WS.EXE`, SHA-256 `535235e6a392d344948d065a5553798e6119b2a0c25ccbaca2221b6b4860904d`. Three isolated DOSBox runs on 2026-10-17 used synthetic 128-byte files: `ABACABA`, `AB` CRLF `CD`, and `aBaA`. Their retained local directories are `runtime-openstar-qchar-01`, `runtime-openstar-qchar-lines-01`, and `runtime-openstar-qchar-case-01` under `C:/Projects/rea/investigations/wordstar`. Eleven `charfind-*.json` oracles identify the exact input manifest, event log, copied carrier, and result screens by SHA-256. The screens and original software stay outside this repository. Run `python tools/verify-local-evidence.py C:/Projects/rea/investigations/wordstar` to verify source identities.

The CLI profile `ws4-character-find-v1` compares cursor, found state, carrier hash, Insert mode, and declared formatting. It accepts `find_character`, `document_start`, and `next_character` only. The implementation is limited to ASCII letters in ordinary one-byte documents with hard CRLF and no dot-command lines. The retained runs used default document mode, single spacing, margins 1/65, and right justification off; other formatting states were not measured. Punctuation, spaces, high-bit cells, soft breaks, Ctrl-L interaction with an earlier text search, and native UTF-8 mode remain outside this profile. The core rejects unsupported characters or document tokens before changing search state. The Windows adapter collects the letter and displays the prompt and failure message; a native-window pixel comparison is still untested.
